# UM14.6 — Android/iOS Store Release Boundary

**Milestone:** 14 — Application Versioning & Update Management  
**Branch:** `cto/um14-6-native-store-release-boundary`  
**Dependency:** UM14.5 / PR #178 accepted and merged

## Objective

Create the canonical official-store release boundary for future AIM Android/iOS applications without fabricating native publication or accepting arbitrary update destinations.

## Deliverables

- Android official Google Play target validation;
- iOS official Apple App Store target validation;
- paired platform publication configuration;
- fail-closed unpublished state;
- package/store-ID matching;
- production-runtime certification coverage;
- ADR-039;
- operator runbook;
- roadmap refinement.

## Out of scope

- Android/iOS application source code;
- Play/App Store submission;
- native UI;
- direct APK/IPA distribution;
- alternative/third-party stores;
- enterprise MDM;
- region-specific store routing;
- backend compatibility overlap (UM14.7).

## Completion criteria

1. Android target accepts only the official Google Play host/path.
2. Android URL package ID exactly matches configured package ID.
3. iOS target accepts only the official Apple App Store host.
4. iOS URL ends in the configured numeric App Store ID.
5. Partial platform configuration fails closed.
6. Unpublished platforms resolve to null and required target lookup fails.
7. Arbitrary HTTPS hosts and sideload destinations are rejected.
8. No native-publication claim is made while native app code is absent.
9. Production runtime certification covers the boundary.
10. Formatting, lint, tests, build, security and exact-head CI are green before merge.
