# F0.8 Sprint Report: Role Lifecycle and Membership Access

**Status:** Implemented on `cto/frontend-foundation`

**Dependency:** F0.7 authenticated Team and Access frontend; accepted S0.4 authorization

## Objective

Complete the tenant access-administration lifecycle without weakening the
membership-bound authorization model. Add the missing tenant membership read
contract, enforce optimistic role versions, and connect assignment mutations
to the existing atomic durable-audit services.

## Delivered

- Added `GET /authorization/memberships`, guarded by
  `authorization.assignments.read` and derived only from the authenticated
  tenant context.
- Membership results are bounded and contain identity display fields, status,
  and active role summaries; deleted memberships and deleted roles are
  excluded.
- Added validated BFF boundaries for membership reads, role update/delete, and
  assignment add/remove.
- Role update and deletion forward strong numeric `If-Match` entity tags.
- System roles remain visibly protected and cannot enter the edit workflow.
- Custom-role editing covers names, descriptions, and live permission
  selection.
- Destructive deletion uses an explicit two-step confirmation.
- The membership directory exposes immediate, audited role assignment toggles
  and respects inactive-membership behavior.
- Backend conflict, stale-version, forbidden, malformed response, expired
  session, and transport failures remain bounded.

## API contract

| Method   | Route                                                    | Permission                         |
| -------- | -------------------------------------------------------- | ---------------------------------- |
| `GET`    | `/authorization/memberships`                             | `authorization.assignments.read`   |
| `PATCH`  | `/authorization/roles/:roleId`                           | `authorization.roles.update`       |
| `DELETE` | `/authorization/roles/:roleId`                           | `authorization.roles.delete`       |
| `PUT`    | `/authorization/memberships/:membershipId/roles/:roleId` | `authorization.assignments.manage` |
| `DELETE` | `/authorization/memberships/:membershipId/roles/:roleId` | `authorization.assignments.manage` |
