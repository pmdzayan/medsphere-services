# Architecture Decision Records

ADRs preserve the context behind major MedSphere decisions.

## Status values

- **Proposed:** Under review; not implementation authority
- **Accepted:** Binding until superseded
- **Superseded:** Replaced by a newer ADR
- **Rejected:** Considered but not selected

## Required sections

Every ADR includes decision, reason/context, alternatives, consequences, implementation constraints, and review triggers.
